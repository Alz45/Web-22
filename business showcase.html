Project 1: Problem-Solving Page

Project Overview

The Problem-Solving Page was developed to demonstrate how I approach a problem in a structured and logical way. The aim was to create a webpage that clearly explains a problem, considers possible solutions and presents a suitable final approach.

My Role

My role was to plan the structure of the page, identify the main problem, research possible solutions and develop the webpage using HTML and CSS. I was also responsible for reviewing the final page and making improvements to its usability and presentation.

Problem Addressed

One of the main challenges was presenting a problem-solving process in a way that was easy for a user to understand. Information can become confusing when there is no clear structure or progression from the problem to the final solution.

Solution

I structured the page into clear sections, including the problem, analysis, possible solutions, selected solution and conclusion. Headings, spacing and visual sections were used to make the information easier to navigate.

Development Rationale

The page was deliberately structured in a logical sequence so that users can follow the development of the solution from beginning to end. I used headings and separate content sections to reduce information overload and make the page easier to scan.

The design also reflects a problem-solving process: first identifying the issue, then analysing it, considering alternatives, selecting an appropriate solution and finally evaluating the result.

I chose a simple and consistent visual design because the primary purpose of the page is communication rather than decoration. HTML was used to create the structure, while CSS was used to control layout, typography, spacing and visual presentation.

Outcome

The completed page provided a clear explanation of the problem-solving process and demonstrated my ability to organise information and communicate a technical process to an audience.

Project 2: Business Intelligence and Dashboards

Project Overview

This project involved working with an international stakeholder to design and develop a decision-making process. Its purpose was to support an international agency in making effective decisions.

My Role

I worked with the information provided by the international agency to plan and develop the dashboard, helping organise the dashboard results so stakeholders can find the information easily.

Problem Addressed

The stakeholder needed a dashboard that compared results across different income levels and clearly explained why the comparison was fair.

Solution

I created a dashboard with clear information for the stakeholder, using different chart types to represent key points. I also created a guidance page to help the stakeholder navigate and interpret the dashboard effectively.

Outcome

The dashboard provides a clear overview of the information, making it easier for the stakeholder to find and use key details.
